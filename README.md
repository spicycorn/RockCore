# RockCore · 岩心围岩类别评价系统 2.0

> **Excel 现场记录导入 + 完整性自动判级 + 围岩初步分类 + 柱状剖面/平面可视化 + 统计导出** 的 Windows 桌面工具。
> 依据 **DL/T 5894-2025《压气储能电站工程地质勘察规范》** 设计，面向**压缩空气储能电站岩心围岩评价**。
> 2.0 为彻底重写版：判定口径与 1.x 完全一致，界面与引擎全部重做。

## ✨ 功能特性

- **项目 / 钻孔管理**：左侧项目树 + 右侧工作区，数据本机 SQLite 持久化（`rockcore.db`）。
- **Excel 数据导入（v12 模板，一行一回次）**：一钻孔一文件，「基本信息」填孔号；「岩心记录」每回次一行，岩心段1..20 按由浅到深一段一格——整段只填长度（≥0.1m），不足10厘米破碎带填 `长度,块数`（如 `0.08,3`），碎屑与整段保持出土顺序（柱状图依赖）；RQD 列 Excel 自动计算（软件重算）；行尾选填岩质/结构类型/坚硬程度（联动下拉）。第 2 行为黄底填写提示（数据从第 3 行起）。软件按原始数据重算全部指标；导入前逐行红/黄校验（多记阻断、少记警告），同钻孔重复导入整体替换旧批次。
- **完整性判级（表 F.0.4）**：`n = 整段格数 + 碎屑块数 → S = 进尺×100÷n (cm)`，**只按平均间距 S 查判定表**；判定表可在「设置」中编辑。
- **记录段 → 岩体段归并**：先把相邻、间距相容的记录段归并成岩体段（最小段厚、间距容差可调），**先归并、后判级**；原始记录逐行保留在回次统计中可溯源。
- **围岩分类（表 F.0.2）**：岩质 / 结构类型 / 完整程度 / 地下水 / 坚硬程度 / 均一性 / 洞轴线夹角七元查表判定；缺项明确提示，**不降级、不伪造结果**；分段页支持批量应用与手动覆盖完整性。
- **柱状剖面图**：按真实倾角绘制孔轴线，分段沿轴着色（围岩类别带 > 完整性带 > 岩性带），RQD 折线、深度刻度、孔口/孔底/水位标记，一键导出 PNG。
- **平面布置图**：孔口坐标散点 + 洞轴线方位（0=北，顺时针）。
- **统计与导出**：围岩类别 / 完整性占比（厚度加权饼图）、RQD 分布柱状图；分段成果一键导出 **Excel / CSV**。
- **钻孔附件**：右键钻孔或导入页「附件…」为钻孔附加岩心照片等文件（≤30MB），base64 内嵌保存在本机数据库；双击放大预览、右键另存/删除，随钻孔级联清理。
- **多入口操作**：每个常用操作均有 按钮 / 右键菜单 / 菜单栏 / 拖拽 / 快捷键 多种入口。

> 判定链路完全基于现场实测原始数据，Excel 公式列仅供现场查看、导入时全部重算，结果可复现、可溯源。

## 🧱 技术栈

| 层 | 技术 |
|----|------|
| 桌面壳 | Tauri 2（Rust 侧零业务逻辑，仅文件读写与内置模板） |
| 前端 | React 19 + TypeScript 5.7 + Vite 6 + Tailwind CSS 4 |
| 图表 | ECharts 5（按需引入） |
| Excel | exceljs（导入解析 + 成果导出） |
| 数据 | SQLite（`@tauri-apps/plugin-sql`） |
| 状态 | zustand |
| 测试 | vitest（判定引擎黄金用例 67 项） |

```
RockCore/
├── .github/workflows/build.yml   # GitHub Actions：测试 + 构建 + Release
├── app/                          # 全部应用代码（Tauri 2 工程）
│   ├── src/engine/               # 判定引擎（纯 TS，无 UI 依赖，vitest 覆盖）
│   ├── src/db/                   # SQLite schema 与仓储
│   ├── src/views|components/     # 界面（导入/回次/分段/柱状图/统计/设置）
│   ├── scripts/                  # 模板生成与 CI 校验脚本
│   └── src-tauri/                # Rust 壳（3 个命令）+ 内置导入模板
├── docs/
│   ├── 使用说明.txt               # 完整操作流程与计算口径（随 Release 分发）
│   └── *.png                     # 规范参考表（DL/T 5894-2025）
└── LICENSE                       # Apache 2.0
```

## 🏗️ 开发

> 需要 **Windows 10/11 x64** + **Node.js 22**；构建安装包另需 Rust 工具链（`rustup` 默认 stable 即可）。

```powershell
cd app
npm ci
npm test          # 判定引擎测试（67 项）
npm run dev       # 浏览器开发模式（文件对话框等桌面能力不可用）
npm run tauri:dev # 完整桌面开发模式
```

导入模板由 `npm run gen:template` 重新生成到 `app/src-tauri/resources/`，CI 会用 `npm run validate:template` 校验其可解析。

## ☁️ GitHub Actions

- 推送到 `main` / PR → 自动跑 测试 + 前端构建 + 模板校验 + Rust 编译检查。
- 打标签 `v*`（如 `v2.0.1`）→ 自动创建 **GitHub Release**，附 **Windows 安装包（.exe）**，并上传 **《岩心回次统计导入模板》xlsx** 与 **使用说明**。

## 📥 下载

到 [Releases](../../releases) 下载 Windows 安装包（`RockCore_vX.Y.Z_x64-setup.exe`，双击安装）。首次使用请先在软件内 **文件 → 下载导入模板**。
